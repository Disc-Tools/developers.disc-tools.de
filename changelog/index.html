API Changelog

Updates to the Disc-Tools API and developer portal.

November 18, 2026

New endpoints and API monitoring

  • Batch Link Cleaner

    POST /api/v1/link-cleaner/batch

    Clean up to 20 URLs in one request and get a result for each URL in input order.

  • Discord Timestamp

    POST /api/v1/discord/timestamp

    Convert a UTC date or Unix timestamp to Discord timestamp markup.

  • Public API Status

    The status page shows individual reachability checks and response times for API endpoints, Discord login and Premium verification. Monitoring clients can check login configuration and Premium lookup availability via GET /api/v1/status.

  • Premium portal access and API Playground

    Anyone with active Disc-Tools Premium can access the developer portal after signing in with Discord. In the Playground, you can try Link Cleaner with your own API token.
