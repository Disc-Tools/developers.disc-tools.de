# Security policy

## Supported version

Security fixes apply to the current version of the developer portal on
the `main` branch.

## Report a vulnerability

Email [info@disc-tools.de](mailto:info@disc-tools.de) with the subject
`Security report: Developer Portal`. Include the affected URL or
component, the potential impact, and enough detail for the team to
investigate. Redact API tokens, session credentials, and personal data.

Keep reports private while the Disc-Tools team investigates and
coordinates disclosure.
