Link Cleaner quickstart

  1. Sign in to the developer portal and open API tokens.
  2. Create a token and copy it. The portal displays the full token only when you create it.
  3. Run the example in Bash and paste the token at the prompt.
read -rs -p 'API token: ' DISC_TOOLS_API_KEY; printf '\n'
curl -sS -i https://developers.disc-tools.de/api/v1/link-cleaner \
  -A 'DiscToolsExample/1.0' \
  -H "Authorization: Bearer $DISC_TOOLS_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://example.com/watch?v=42&utm_source=discord"}'
unset DISC_TOOLS_API_KEY

Expect HTTP 200 and a JSON response whose url is https://example.com/watch?v=42. If you write your own client, set a descriptive User-Agent such as MyDiscordBot/1.0.

POST /api/v1/link-cleaner

Send a JSON object with one absolute HTTP or HTTPS url of up to 4,096 characters. The API removes UTM parameters and common ad click IDs. It processes the URL as text.

A successful response contains url, removed, and request_id.

  • 400 — Check that the JSON contains an absolute HTTP or HTTPS URL.
  • 401 — Check the Bearer token and confirm your account still has API access. Create a new token if the old one was revoked.
  • 429 — Slow down requests. Wait for Retry-After when present. Otherwise, wait and increase the delay between retries.
  • 503 — The service is temporarily unavailable. Try again after a short delay.
