API access

Portal access currently requires active Disc-Tools Premium and a staff role in the Disc-Tools server. Follow the announcements for public beta access and limits.

Link Cleaner quickstart

Send a URL to POST /api/v1/link-cleaner with a Bearer token. Set DISC_TOOLS_API_KEY to a key created in the portal to run this example.

Read the full quickstart in the portal (staff sign-in required).

Planned API

Link Cleaner is planned for the first beta. You can try all three tools in your browser today.

  • Link Cleaner

    If your bot forwards links from a submissions channel, pass each URL through the cleaner before posting it. In the example above, utm_source is removed and v=42 still identifies the video.

    The same step fits into a script that saves shared links to a reading list or moderation log.

  • Snowflake Decoder

    A Discord ID contains the time the object was created. A moderation bot could decode a user ID when someone joins and include the account creation time in a staff log.

    The timestamp is part of the ID itself. A user’s join date for a particular server is a separate piece of information.

    Open Snowflake Decoder

  • Timestamp Generator

    Put a timestamp like <t:1794592800:F> in an event announcement and Discord displays the date and time in each reader’s local time zone. Use :R instead of :F for a relative time such as “in 2 hours”.

    A scheduling bot could generate that markup from the event’s start time and reuse it in the announcement and reminder.

    Open Timestamp Generator

FAQ

Can I create an API key today?

Eligible Disc-Tools staff can create keys in the portal. Public key creation opens with the beta.

Does signing in to Disc-Tools also sign me in here?

The developer portal has its own Discord sign-in and session.

Where will API updates be posted?

Check the Disc-Tools announcements for updates on beta access and the API reference.
