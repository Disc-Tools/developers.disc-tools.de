Scope

These terms cover the developer portal and API at developers.disc-tools.de. Any terms applicable to your Disc-Tools Premium subscription also apply to that subscription.

Portal and API access

Portal access requires Discord sign-in, an eligible staff role and active Disc-Tools Premium. API requests require a valid key and active Premium. The API is in beta, and endpoints and limits may change as it develops.

API keys

Keep keys private. Store them on the server running your integration and revoke any key that is lost or exposed. You can revoke a key in the developer portal. Keys with an expiration stop working at the end of their lifetime.

Acceptable use

Respect rate limits and use the service lawfully. Do not use it to access accounts or data without authorization, interfere with the service or distribute malware or spam. Submit only data you are permitted to share.
